## ✨ Overview

**N9 AI Academy** ไม่ใช่แค่เว็บไซต์แนะนำเครื่องมือ AI แต่เป็นประสบการณ์การเรียนรู้ผ่าน Interactive Storytelling

เว็บไซต์ใช้ Scroll-driven Animation เพื่อพาผู้เข้าชมเดินทางผ่านเนื้อหาแต่ละส่วนอย่างต่อเนื่อง พร้อมดีไซน์ที่เน้นความเรียบง่าย ทันสมัย และการเคลื่อนไหวที่ลื่นไหล

### 🎬 What You Can Learn

| Category | Description |
|---|---|
| 🌌 What If Stories | สร้างเรื่องราวสมมติและเหตุการณ์เหนือจินตนาการ |
| 🧟 Zombie Apocalypse | สร้างวิดีโอแนวโลกหลังหายนะและซอมบี้ |
| 🎨 Flat 2D Cartoon | สร้างการ์ตูน 2D และคลิปสั้นด้วย AI |

## 🚀 Features

### 01 — Immersive Hero Experience
- Blur-to-Focus Animation
- Animated Typography

### 02 — Scroll-driven Storytelling
- Sticky Scroll Sections
- Pinned Content Showcase
- Scroll-based Transitions
- Progressive Content Reveal

### 03 — Interactive Showcase
- Role & Workflow Showcase
- Sticky Notes
- Pain Point Presentation
- Animated Value Cards

### 04 — AI Production Workflow

เรียนรู้กระบวนการสร้างวิดีโอ AI ตั้งแต่ต้นจนจบ

- **Story** — วางโครงเรื่องและสร้างไอเดีย
- **Prompt** — เขียนคำสั่งสำหรับ AI
- **Motion** — สร้างภาพเคลื่อนไหว
- **Export** — เตรียมวิดีโอสำหรับเผยแพร่

### 05 — Performance & Responsive
- Responsive Desktop / Tablet / Mobile
- `prefers-reduced-motion` Support
- Optimized Animation Logic
- No External Image Dependencies
- Gradient-based Visual Placeholders

## ⚡ Getting Started

### 1. Clone Repository

```bash
git clone https://github.com/jikkhg/n9-ai-academy.git
```

### 2. Open Project

```bash
cd n9-ai-academy
```

เปิดไฟล์ `index.html` ผ่านเบราว์เซอร์ หรือใช้ VS Code Extension อย่าง Live Server

### 3. Run Development Server

หากใช้ VS Code:

1. เปิดโฟลเดอร์โปรเจกต์
2. ติดตั้ง Extension: Live Server
3. คลิกขวาที่ `index.html`
4. เลือก Open with Live Server

> **Note:** โปรเจกต์ใช้ GSAP และ ScrollTrigger ผ่าน cdnjs จึงต้องเชื่อมต่ออินเทอร์เน็ตเพื่อโหลด Animation Library

### Deployment Steps

1. เปิด GitHub Repository
2. ไปที่ `Settings`
3. เลือก `Pages`
4. ตั้งค่า Source เป็น `Deploy from a branch`
5. เลือก Branch: `main`
6. เลือก Folder: `/ (root)`
7. กด Save

หลังจาก GitHub Pages Build สำเร็จ เว็บไซต์จะพร้อมใช้งานผ่าน URL ด้านบน

## 📱 Design Philosophy

N9 AI Academy ถูกออกแบบโดยยึดแนวคิด 3 ข้อ

- **Minimal** — ลดความซับซ้อนและเน้นเนื้อหาที่สำคัญ
- **Immersive** — ใช้ Motion และ Scroll สร้างประสบการณ์ที่น่าสนใจ
- **Accessible** — รองรับอุปกรณ์หลากหลายและผู้ใช้ที่ต้องการลด Motion
